# TPQ Al Muhajirin Harmoni - Sistem Manajemen

Platform manajemen terintegrasi untuk TPQ Al Muhajirin Harmoni berbasis Laravel 10. Harmoni

Struktur dasar website TPQ Al Muhajirin Harmoni.

## Halaman utama
- `index.html` - Beranda
- `admin.html` - Halaman Admin
- `blog.html` - Sistem informasi / blog TPQ
- `new-santri.html` - Form penerimaan santri baru
- `santri.html` - Data santri aktif dan tidak aktif
- `evaluation.html` - Form penilaian santri
- `teachers.html` - Data guru
- `organization.html` - Data struktur organisasi
- `finance.html` - Data keuangan
- `documentation.html` - Dokumentasi kegiatan
- `forum.html` - Forum diskusi

## Folder
- `css/style.css` - gaya desain islami minimalis
- `js/main.js` - script ringan interaksi tombol
